# قطارات الجزائر | Trains DZ

موقع ثابت مستقل مستخرج من مكونات القطارات في `imadtbn/dz_portal` عند commit `eb925e3`، بواجهة عربية متجاوبة. المصدر: https://github.com/imadtbn/dz_portal

## التشغيل والفحص

`npm run dev` ثم افتح http://localhost:8080 . استخدم `npm test` لفحص البيانات ومحرك الرحلات والروابط والصور. لا يحتاج الموقع إلى بناء أو حزم npm.

## الصفحات

- `index.html`: بحث سريع، إحصائيات من البيانات، الجهات والمحطات المفضلة.
- صفحات البحث ولوحة المحطة والخريطة مستقلة؛ التفاصيل أدناه.
- `sectors/sntf-trip.html`: تفاصيل الرحلة، تاريخ التشغيل والجدول المصدر.
- `sectors/sntf.html`: معرض الجداول وخدمات SNTF.
- `about.html`: طريقة عمل البيانات والخصوصية المحلية.

## تحديث البيانات يدويًا بين المستودعين

لا توجد مزامنة تلقائية أو قاعدة بيانات مركزية. كل موقع يقرأ نسخته المحلية. عدّل ملفات `assets/data/sntf/` في أي مستودع، ثم:

1. شغّل فحص البيانات `node scripts/validate-sntf-data.mjs`.
2. انسخ مجلد `assets/data/sntf/` كاملًا بنفس المسار إلى المستودع الآخر، بعد التأكد من عدم وجود تعديلات أحدث فيه.
3. انسخ صور الجداول الجديدة أو المعدلة إلى `assets/train-schedules/` مع الحفاظ على الأسماء والمسارات.
4. شغّل فحص البيانات في المستودع الآخر، وراجع فرق الملفات ثم ارفع التعديلين.

حافظ على معرّفات المحطات والرحلات، إحداثيات `geo_verified`، القيم `null`، أيام التشغيل والاستثناءات. حدّث تاريخ `updated` في الملفات المعدلة. لا تنسخ ملفات الواجهة أو CSS أو JS بين المشروعين. لا تعدّل روابط المصدر داخل JSON لمجرد تغيير تصميم الموقع: الواجهة تحول صور الجداول المحلية دون تغيير بيانات المصدر.

ملف `verified-geo-lock.json` موروث كما هو؛ قد يحتوي إحداثيات أقدم من `stations.json`. لا تستخدمه لاستبدال الإحداثيات تلقائيًا.

## النشر

Workflow `pages.yml` يفحص البيانات ثم ينشر الموقع عبر GitHub Pages. يلزم اختيار **GitHub Actions** في Settings → Pages → Source. المسار المتوقع: https://imadtbn.github.io/trains-dz/

## حدود البيانات والتشغيل

المواقيت مجدولة، لا تتبع مباشر ولا تأخيرات فعلية. الرحلات بتبديل واحد تفترض الانتقال في المحطة نفسها بين 30 و180 دقيقة. الخريطة تعرض مواقع المحطات ولا تخمّن مسار السكك. الصور وبلاطات الخريطة تحتاج الإنترنت. الخدمة العاملة تحفظ الصفحات والبيانات المطلوبة بعد زيارتها وتفضّل الشبكة عند عودتها. المفضلة محلية. وحدة AdSense يدوية واحدة في كل صفحة محتوى، خارج الهيدر، مع تحميل قرب مجال الرؤية. الصفحة 404 بلا إعلانات.

## الهوية والمشاركة والإعلانات

خط Noto Sans Arabic من Google Fonts مع display=swap وخط احتياطي، وأيقونات PNG/SVG/ICO وApple Touch 180px. مشاركة الموقع عبر روابط المنصات أو قائمة الجهاز أو نسخ الرابط؛ لا يُرسل أي منشور تلقائيًا.

- الرئيسية ومعرض الجداول: وحدة داخل الخلاصة `7867079394`.
- المخطط وتفاصيل الرحلة وعن المنصة: وحدة صورية متجاوبة `3143411927`.
- الناشر: `ca-pub-5656416032906373`.
- لكل صفحة وحدة يدوية واحدة ومساحة محجوزة؛ لا يتم إخفاء iframe أو تغيير موضعه بعد التحميل.
- loader يرسل طلبًا واحدًا لكل عنصر بعد اقترابه من الشاشة والتأكد من عرضه. حالة unfilled تبقي المساحة دون قفز المحتوى.
- الإعلانات التلقائية وAnchor/Vignette تتحكم فيها إعدادات AdSense؛ للحصول على إعلان واحد فقط وبدون إعلانات أعلى الصفحة عطّل Auto ads لهذا الموقع من حساب AdSense. الشفرة المحلية لا تغير إعدادات الحساب.
- Structured Data يصف المنصة كدليل مستقل، وشركة SNTF كمشغل الرحلة فقط؛ لا أسعار تذاكر أو تقييمات مفترضة.

## التواصل والدعم

`contact.html` يضم نموذج Google Forms المقدم من مالك الموقع بإطار مضمّن ورابط فتح مباشر بديل. لا يوجد إرسال محلي أو رسالة نجاح وهمية؛ التأكيد داخل Google Forms. نشر الصفحة لا يغيّر إعدادات النموذج أو استقبال الردود أو الإشعارات؛ تظل تحت إدارة مالك النموذج. البلاغات لا تعدّل البيانات تلقائيًا.

## البحث والمفضلة وخلفيات البطاقات

البحث بالكتابة يدعم العربية والفرنسية والتهجئات البديلة والأسهم وEnter وEscape. الاختيار يُرسل معرّف المحطة لا الاسم.
صفحة favorites.html تجمع المحطات والمسارات والجداول المصورة وجداول القطارات (الأخيران ضمن جداول الرحلات). أزرار الحفظ في لوحة المحطة، بطاقات المسارات، معرض الجداول وصفحة تفاصيل القطار.
تستخدم localStorage بالمفتاح trains-dz-saved-v2 مع ترحيل محفوظات trains-dz-favorites القديمة دون حذف المفتاح القديم. لا مزامنة بين الأجهزة. فشل التحميل لا يحذف محفوظات المستخدم.
خلفيات البطاقات قابلة للاستبدال في assets/images/cards وخصائص --card-image بنهاية site.css؛ SVG رموز مؤقتة، وصورة الخريطة من المرفق.

## خدمات القطارات المستقلة
- `sectors/sntf-search.html`: البحث بين محطتين.
- `sectors/sntf-station.html`: لوحة محطة يختارها المستخدم بالكتابة أو تحديد الموقع؛ لا توجد محطة افتراضية. رابط `?station=ID` يفتح المحطة المحددة.
- `sectors/sntf-map.html`: الخريطة والخطوط؛ يدعم `?route=ID` و`?category=ID` و`?station=ID`.
- `sectors/sntf-trains.html`: تحويل متوافق للروابط القديمة، مع الحفاظ على معاملات الرابط.
لكل صفحة ملف تشغيل مستقل يستدعي `rail-runtime.js` المشترك؛ مكتبة Leaflet لا تُطلب إلا في صفحة الخريطة. تبقى ملفات البيانات مشتركة البنية، ونسخها بين المستودعين يدويًا.
